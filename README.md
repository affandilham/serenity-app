# Serenity

> **S**mall **E**fforts **R**estore **E**ase; **N**ew **I**ntentions **T**ransform **Y**ou.

Serenity adalah aplikasi Flutter pribadi, offline-first, untuk membantu pengguna
memahami pola merokok, mempersiapkan perubahan, dan melewati craving tanpa nada
yang menghakimi. Aplikasi ini adalah pendamping kebiasaan, bukan pengganti saran
dokter atau tenaga kesehatan.

## Status

Milestone aktif: **02 — Onboarding & Profile**. Lihat [project status](docs/PROJECT_STATUS.md)
dan [spesifikasi produk](docs/APP_SPEC.md) untuk konteks lengkap.

## Menjalankan proyek

```bash
flutter pub get
flutter run
```

## Dokumentasi dan Git

Semua berkas `.md` berikut **layak di-push** karena merupakan spesifikasi,
keputusan arsitektur, dan konteks kerja yang dibutuhkan kontributor atau coding
agent berikutnya:

- `README.md`
- `AGENTS.md`
- `docs/APP_SPEC.md`
- `docs/PROJECT_STATUS.md`
- `docs/milestones/`

Jangan simpan data pribadi pengguna, kredensial, catatan personal, atau export
aplikasi di repository. Gunakan `docs/private/` (sudah di-ignore) atau folder
Documents lokal untuk materi tersebut.
